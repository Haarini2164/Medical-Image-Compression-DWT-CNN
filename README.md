# 🧠 CNN-Enhanced DWT Medical Image Compression

## 📌 Overview
This project proposes a hybrid model combining:
- Discrete Wavelet Transform (DWT)
- Convolutional Neural Networks (CNN)

for efficient **lossless medical image compression**.

## 🚀 Key Features
- Lossless compression (no quality loss)
- Improved compression ratio (15–23%)
- Works on MRI, CT, X-ray images

## 🛠️ Methodology
1. Preprocessing (resize, normalize)
2. DWT decomposition
3. CNN autoencoder
4. Reconstruction using inverse DWT

## 📊 Results
- PSNR → High
- SSIM → ~1
- Compression Ratio → ~3.45x
